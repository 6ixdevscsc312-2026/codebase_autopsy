# bob_sessions/

This folder holds proof of IBM Bob 2.0 usage, as required by the hackathon
deliverables: **"Code repository, including IBM Bob task session summary
screenshots"** and **"The repository should include each team member's
screenshots of IBM Bob task session summaries."**

## What's required

Screenshots of the **Bob task session summary** (the consumption/summary
panel shown when you click a task's header in Bob IDE chat) — not just a
screenshot of Bob's output text.

## How to capture them (per the hackathon mentor guidance)

1. In Bob IDE chat, open **Tasks** to display the task list.
2. Open each task related to this project.
3. Click the **task header** to display the task session consumption
   summary panel.
4. Screenshot that summary panel (PNG preferred).
5. Save the file into this folder using the naming convention below.

## Naming convention

```
<teamname>_task<NN>_<short-description>.png
```

Example: `soloramafemo_task01_ast_ingestion_setup.png`

## Checklist (fill in as you go)

- [ ] Screenshot: setting up `ingest.py` (AST repo walker)
- [ ] Screenshot: setting up `graph.py` (dependency graph / cycle detection)
- [ ] Screenshot: wiring `bob_client.py` to the real Bob Shell CLI
- [ ] Screenshot: building the drift-analysis prompt / `main.py` orchestration
- [ ] Screenshot: any debugging/refactor task sessions with Bob

Note: this README and the folder structure are provided so the real
screenshots have somewhere to go — the screenshots themselves have to come
from your own live Bob IDE session, since they can't be generated outside
of it.
